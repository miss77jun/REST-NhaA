# 300→400K 标准 REST2 接受率先导报告 (2026-10-22)

- 配置: 20 副本, T_ref=300K, T_max=400K, --no_local_heating, 平衡 0.4 ns + 生产 0.4 ns/副本
- 平台: node38 A40 (job 7654893), 总耗时 1.84 h
- 产物: 4AU5/outputs/ (本先导目录), 日志 00_verification/pilot_400k.log

## 相邻交换接受率 (19 对, 各 100 次尝试)

| 指标 | 值 |
|---|---|
| 范围 | 24% – 36% |
| 均值 | ~29.5% |
| 分布 | 无断点、无异常对、沿梯子均匀 (0-1: 35%, 6-7: 24% 为两极) |
| exchange_quality | **pass** (全部 ≥20%) |

## 判定: 20 副本梯子定案 ✓

均值 29.5% 落在 20-40% 目标带中部偏下, 与"间隔比 v4.3 宽 1.47×"的外推一致
(v4.3: 50%)。加副本 (22-24) 可到 ~35-40% 但收益有限; 减副本 (18) 会压到
~25% 以下留边不足。**建议维持 20 副本**。

## Walker 混合 (0.4 ns, 仅参考)

- 槽位覆盖: 每 walker 30-80% 槽位, 占位 RMSE 0.8-2.0
- round trip: 0 (时长不足的正常表现; round trip ~n² 标度, 判定靠生产期覆盖率+端点访问)

## 生产成本估算

先导吞吐 ~8.7 ns/h (单 A40, 含平衡) → 50 ns × 20 副本 = 1000 ns ≈ **4.8 天/卡**。
v4.4 脚本为单卡设计, 多卡需脚本支持 (可与学生讨论)。
